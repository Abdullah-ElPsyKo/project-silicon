# Project Silicon

> Build the computing industry from raw silicon to AI infrastructure.

Project Silicon is a factory automation game inspired by games such as Factorio, Dyson Sphere Program and Shapez 2.

Instead of manufacturing generic products, the player builds the entire computing industry, progressing from raw natural resources to modern computing infrastructure.

Eventually players will manufacture and deploy:

- Silicon
- Wafers
- Integrated Circuits
- CPUs
- GPUs
- Motherboards
- Servers
- Networking Equipment
- Data Centers
- AI Infrastructure

The focus is on automation, optimization, logistics and large-scale industrial design.

---

## Vision

Project Silicon is designed around one central philosophy:

> **If a mechanic exists only because it is realistic, it probably doesn't belong.**
>
> Every system should create meaningful decisions, satisfying automation and interesting optimization problems.
